# Samoylo57.github.io

This repository contains the source for the website served via GitHub Pages.
It is configured to use the custom domain **samoylo57.com**. The domain is
specified in the `CNAME` file.

To make sure the site is available on `https://samoylo57.com`, configure your
DNS records accordingly (either a CNAME pointing to `samoylo57.github.io` or
A records pointing to GitHub Pages IP addresses) and enable HTTPS in the
GitHub Pages settings.
